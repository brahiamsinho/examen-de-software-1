# Project Vision

Examen-1-Software is a full-stack template project built for an exam /
learning context. It scaffolds a Django + PostgreSQL backend (exposed via
Django REST Framework), a Next.js + TypeScript frontend, and a Flutter
mobile app, all wired together with Docker Compose for local development
(mobile runs on the host/emulator, not in a container). At this stage it
contains no business logic — it is pure infrastructure scaffolding meant
to be extended once real requirements are defined.
